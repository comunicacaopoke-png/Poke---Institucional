# Ferramentas POKE

Hub estático das ferramentas POKE, publicado com o site institucional no GitHub Pages.

- `/ferramentas/` — cards das ferramentas.
- `/ferramentas/poke-cut/` — POKE CUT: edição de vídeo com IA no navegador. Quadros e transcrição (Whisper via transformers.js) são gerados localmente; só quadros reduzidos, transcrição e brief vão para a API da Anthropic, com a chave informada na própria ferramenta (salva só no navegador de quem usa). Fonte: `poke-cut-preview/dist/` do projeto Editor de vídeos.

As páginas usam `noindex,nofollow`. GitHub Pages não autentica por rota: não publique aqui nada que dependa de segredo ou de dados privados no servidor.
